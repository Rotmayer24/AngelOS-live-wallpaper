# Live Wallpaper (angelOS)

Плагин по `docs/PLUGINS.md` angelOS. Файлы MP4/WebM (QtMultimedia) и GIF/WebP (AnimatedImage).
Настройки хранятся самим angelOS (`plugin.get/set` → `~/.config/angelos/settings.json`).

## Режимы
- **Карточка** — `DesktopWidget.qml`: окно «live-wallpaper.exe» на рабочем столе (ПКМ → Вид → добавить). Без звука.
- **Полный экран** — `Main.qml`: слой `angelos-livewall` (WlrLayer.Background) на каждом экране; ввод проходит сквозь него.
  Звук — только на первом экране.

## Полное выключение
Переключатель «Включены» (Настройки плагина и кнопка питания на панели): слой удаляется, `MediaPlayer` выгружается, карточка пустеет.
Настройки и выбранный файл сохраняются. Сам плагин целиком отключается в Настройки → Плагины.

## Автопоиск
Settings → Библиотека: сканирует `~/Pictures` (папку можно сменить) с подпапками до глубины 8 через `find`; MP4/WebM/MKV/MOV,
GIF — включён по умолчанию, WebP — по галочке (часто статичные). Скрытые папки пропускаются. Выбор из списка или «Случайные».

## Виджеты и звук
- Поверх видео в слое заново рисуются «лица» виджетов (`DesktopWidgetHost`, role `face`). Ввод обслуживают штатные копии angelOS.
- Звук по умолчанию выключен: тогда у `MediaPlayer` нет `audioOutput`, и плеер/спектр angelOS обои не видят. При включённом звуке
  видимость в плеере не гарантируется.

## Автопауза
Пауза при `Motion.still` (режим движения «off») и при полноэкранном окне на экране (`Shell.fullscreenOn`); mute на полноэкранном окне.

## Не реализовано
Ограничение FPS, профили производительности, выбор монитора для отдельных файлов — QtMultimedia этого не даёт.

## Не проверено (нужен живой angelOS)
- Правое меню рабочего стола и копии ввода живут в слое `angelos-desktop`; если слой видео окажется выше него, меню может прятаться под видео.
- Все QML-файлы не запускались; `qmllint` недоступен.

## Установка / удаление
    cp -a live-wallpaper ~/.config/angelos/plugins/     # затем Настройки → Плагины → включить
    rm -rf ~/.config/angelos/plugins/live-wallpaper     # удаление

## GIF/WebP
`AnimatedImage`; если Qt не смог открыть файл (например, нет плагина WebP из qt6-imageformats), плагин сам переключается на ffmpeg-плеер и пишет предупреждение в журнал quickshell.
Путь к файлу кодируется для URL, так что пробелы, `#` и `%` в именах допустимы.

## FPS и фризы
- «Лимит FPS»: картинка копируется в текстуру по таймеру (`ShaderEffectSource`, `live: false`), на экран кадры идут не чаще лимита. Декодирование не ускоряется и не замедляется; частота кадров самого файла выше не станет.
- «Только на первом экране»: на каждом экране видео декодируется отдельно, второй экран удваивает нагрузку.
- Возможные рывки на стыке цикла: Qt делает seek в начало (`loops: Infinite`); на уровне плагина это не убирается.
- Аппаратное декодирование Qt включается переменной окружения оболочки (не плагином), см. документацию Qt Multimedia FFmpeg (`QT_FFMPEG_DECODING_HW_DEVICE_TYPES`) — не проверено.
- Лучший способ убрать фризы: перекодировать обои в 1080p/30 fps (H.264 или VP9).

## Масштаб
Режим (Fill/Fit/Stretch) + «Увеличение» 0.25–3× и сдвиг ±50 % по осям; применяется к слою и к карточке. Сброс — одной кнопкой.
